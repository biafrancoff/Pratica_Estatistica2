1 Contextualização

1.1 ANOVA Clássica

Objetivo:

Comparar médias de k grupos

Hipótese:

\[ \begin{cases} H_0: \mu_1 = \mu_2 = \cdots = \mu_k \\ H_1: \exists\, i,j \text{ tal que } \mu_i \neq \mu_j \end{cases} \]

Estatística de teste:

\[ F = \frac{QM_{Entre}}{QM_{Dentro}} = \frac{\frac{SQ_{Entre}}{k-1}} {\frac{SQ_{Dentro}}{N-k}} \]

\(QM_{Dentro}\) é um estimador não viesado para \(\sigma^2\)

\[ E(QM_{Dentro}) = \sigma^2 \]

Suposições:

  • Independência
  • Normalidade
  • Homocedasticidade

\[ \sigma_1^2 = \cdots = \sigma_k^2 \]

Interpretação do teste:

  • \(F \approx 1\): a variação entre as médias dos grupos é semelhante em relação à variação dentro dos grupos

  • \(F\) elevado: a variação entre as médias dos grupos é maior em relação à variação dentro dos grupos

  • \(p\)-valor < \(\alpha\): rejeitamos \(H_0\)

1.2 O papel da Homogeneidade

Onde é utilizada?

  • A homogeneidade aparece no denominador:

\[ QM_{\text{Dentro}} \]

  • Estima uma variância comum para todos os grupos

\[ F = \frac{QM_{\text{Entre}}} {\color{#2563eb}{QM_{\text{Dentro}}}} = \frac{ \dfrac{SQ_{\text{Entre}}}{k-1} }{ \color{#2563eb}{ \dfrac{SQ_{\text{Dentro}}}{N-k} } } \]

O problema da heterogeneidade

Quando:

\[ \sigma_i^2 \neq \sigma_j^2 \]

  • \(QM_{\text{Dentro}}\) pode não representar corretamente o erro

  • A confiabilidade da estatística \(F\) pode ser comprometida

1.3 Teste de Tukey

Objetivo:

Identificar quais pares de médias diferem após rejeitar \(H_0\) na ANOVA

Estatística de teste:

\[ q_{ij} = \frac{\bar{y}_i - \bar{y}_j} {\sqrt{\frac{{QM_{Dentro}}}{n}}} \]

  • Compara pares de médias \(i\) e \(j\)
  • Valores altos de \(q_{ij}\) indicam diferença significativa

2 ANOVA de Welch

2.1 ANOVA de Welch

Quando usar?

Quando a hipótese de homocedasticidade não é satisfeita


Estatística

\[ F_W = \frac{ \sum w_i(\bar{y}_i-\bar{y}_w)^2/(k-1) }{ 1+\frac{2(k-2)}{k^2-1} \sum\frac{1}{n_i-1} \left(1-\frac{w_i}{\sum w_i}\right)^2 } \]

Ideia

  • Cada grupo tem sua própria variância
  • Grupos com menor variância recebem mais peso

\[ w_i=\frac{n_i}{s_i^2} \]

Interpretação de \(\boldsymbol{F_W}\)

  • Numerador: diferença ponderada entre as médias
  • Denominador: correção para variâncias diferentes

2.2 Comparação das Estatísticas

\[ \color{#052034}{ F = \frac{ \frac{\color{#7C3AED}{SQ_{\text{Entre}}}}{k-1} }{ \frac{\color{#2563eb}{SQ_{\text{Dentro}}}}{N-k} } = \frac{ \frac{1}{k-1} \sum_{i=1}^k n_i (\bar{y}_i-\bar{y})^2 }{ \frac{1}{N-k} \sum_{i=1}^k \sum_{j=1}^{n_i} (y_{ij}-\bar{y}_i)^2 } \sim F_{k-1,\,N-k} } \]

\[ \color{#052034}{ F_W = \frac{ \frac{1}{k-1} \sum_i w_i (\bar{y}_i-\bar{y}_w)^2 }{ 1+ \frac{2(k-2)}{k^2-1} \sum_i \frac{1}{n_i-1} \left( 1-\frac{w_i}{\sum_i w_i} \right)^2 } \sim F_{k-1,\,\nu} \;;\; \nu \approx \frac{k^2-1}{ 3\displaystyle\sum_i \frac{\left(1-w_i/\sum_i w_i\right)^2}{n_i-1} } } \]

3 Teste de Games-Howell

3.1 Escolha do método pós-hoc

Após rejeitar a igualdade das médias, queremos descobrir quais pares de médias diferem

Limitação do Tukey

\[ q_{ij} = \frac{\bar{y}_i - \bar{y}_j} {\sqrt{ \frac{\color{#2563eb}{QM_{\text{Dentro}}}}{n} }} \sim q_{k,\color{#2563eb}{gl}} \]

  • Necessita de homocedasticidade
  • Usa o mesmo erro para todos os pares

Estatística de Games-Howell

\[ t_{ij} = \frac{\bar{y}_i - \bar{y}_j} {\sqrt{ \color{#D97706}{ \frac{s_i^2}{n_i} + \frac{s_j^2}{n_j} } }} \sim t_{k,\color{#D97706}{gl_{ij}}} \]

  • Cada par \((i,j)\) usa variância específica
  • Permite variâncias e tamanhos amostrais diferentes
  • Generaliza o teste \(t\) de Welch para comparações múltiplas

3.2 Síntese dos métodos

ANOVA clássica

  • Usa uma variância comum e pressupõe homocedasticidade
  • Pós-teste de Tukey para comparar os pares de médias

ANOVA de Welch

  • Considera a variância de cada grupo
  • Ajusta a estatística \(F\) e os graus de liberdade

Games–Howell

  • Compara os pares de médias após Welch
  • Não exige homogeneidade das variâncias
