1 O problema

2 Uma variância comum é sempre adequada?

O ponto de partida para entender a ANOVA de Welch

2.1 A pergunta da ANOVA

Temos \(k\) grupos independentes. As diferenças observadas entre suas médias podem ser atribuídas apenas à variabilidade amostral?


\[ H_0:\mu_1=\mu_2=\cdots=\mu_k \qquad\text{versus}\qquad H_1:\text{pelo menos uma média difere} \]

2.2 Duas fontes de variação

2.2.1 Entre os grupos

Mede o afastamento das médias dos grupos em relação à média geral.

\[ QM_{Entre}=\frac{SQ_{Entre}}{k-1} \]

2.2.2 Dentro dos grupos

Mede a variabilidade das observações em torno da média de cada grupo.

\[ QM_{Dentro}=\frac{SQ_{Dentro}}{N-k} \]

\[ F=\frac{QM_{Entre}}{QM_{Dentro}} \]

2.3 Quando a ANOVA clássica funciona bem?

2.3.1 1. Independência

Uma observação não determina o valor de outra.

2.3.2 2. Normalidade

Os erros são aproximadamente normais em cada grupo.

2.3.3 3. Homocedasticidade

\[ \sigma_1^2=\cdots=\sigma_k^2 \]

2.4 A variância comum aparece duas vezes

2.4.1 No teste global

\[ F=\frac{QM_{Entre}}{\color{red}{QM_{Dentro}}} \]

\(QM_{Dentro}\) combina as variâncias de todos os grupos.

2.4.2 Nas comparações de Tukey–Kramer

\[ q_{ij}= \frac{|\bar y_i-\bar y_j|} {\sqrt{\dfrac{\color{red}{QM_{Dentro}}}{2} \left(\dfrac1{n_i}+\dfrac1{n_j}\right)}} \]

Os dois procedimentos tratam \(QM_{Dentro}\) como uma boa representação da variância residual de todos os grupos.

2.5 E se as variâncias forem diferentes?

\[ \sigma_1^2\neq\sigma_2^2\neq\cdots\neq\sigma_k^2 \]

Uma única variância combinada deixa de representar adequadamente todos os grupos.

  • O nível real do teste pode se afastar de \(\alpha\).
  • A combinação de variâncias e amostras desiguais pode distorcer \(F\).
  • O problema é maior quando o grupo mais variável tem o menor tamanho amostral.

Precisamos comparar as médias sem impor uma variância comum.

3 A solução de Welch

4 ANOVA de Welch

Cada grupo contribui de acordo com a precisão de sua média

4.1 A mudança essencial

4.1.1 ANOVA clássica

Combina as variâncias em \(QM_{Dentro}\) e atribui peso principalmente pelo tamanho da amostra.

\[ \Longrightarrow \]

4.1.2 Welch

Mantém as variâncias separadas e pondera cada grupo pela precisão.

\[ w_i=\frac{n_i}{s_i^2} \]

4.2 Como os pesos funcionam?

\[ w_i=\frac{n_i}{s_i^2} \qquad W=\sum_{i=1}^{k}w_i \qquad \bar y_w=\frac{\sum_{i=1}^{k}w_i\bar y_i}{W} \]

Maior \(n_i\) \(\Rightarrow\) maior precisão \(\Rightarrow\) maior peso.

Maior \(s_i^2\) \(\Rightarrow\) menor precisão \(\Rightarrow\) menor peso.

4.3 A estatística de Welch

Defina a correção:

\[ C=\sum_{i=1}^{k} \frac{\left(1-\dfrac{w_i}{W}\right)^2}{n_i-1} \]

\[ F_W= \frac{ \dfrac{1}{k-1}\sum_{i=1}^{k}w_i(\bar y_i-\bar y_w)^2 } { 1+\dfrac{2(k-2)}{k^2-1}C } \]

4.4 Por que os graus de liberdade mudam?

\[ F_W\sim F_{\nu_1,\nu_2} \]

\[ \nu_1=k-1 \qquad\text{e}\qquad \nu_2=\frac{k^2-1}{3C} \]

  • \(\nu_2\) pode ser fracionário.
  • O ajuste considera os tamanhos e as variâncias observadas.
  • Isso melhora o controle do erro tipo I sob heterocedasticidade.

6 Games–Howell

Se Welch rejeita \(H_0\), quais pares diferem?

6.1 Por que Tukey não acompanha Welch?

Aspecto Tukey–Kramer Games–Howell
Variância no denominador \(QM_{Dentro}\) comum \(s_i^2\) e \(s_j^2\) separadas
Graus de liberdade Iguais em todos os pares Calculados para cada par
Variâncias iguais Necessárias Não necessárias
Tamanhos iguais Não são obrigatórios Não são obrigatórios
Combinação usual ANOVA clássica + Tukey Welch + Games–Howell

6.2 Comparação entre dois grupos

Para cada par \((i,j)\), o Games–Howell utiliza o erro-padrão:

\[ EP_{ij}=\sqrt{\frac{s_i^2}{n_i}+\frac{s_j^2}{n_j}} \]

\[ t_{ij}=\frac{|\bar y_i-\bar y_j|}{EP_{ij}} \]

Cada comparação utiliza apenas as variâncias dos dois grupos envolvidos.

6.3 Graus de liberdade de cada par

O ajuste de Welch–Satterthwaite é:

\[ \nu_{ij}= \frac{ \left(\dfrac{s_i^2}{n_i}+\dfrac{s_j^2}{n_j}\right)^2 } { \dfrac{(s_i^2/n_i)^2}{n_i-1} + \dfrac{(s_j^2/n_j)^2}{n_j-1} } \]

Como \(\nu_{ij}\) depende de \(i\) e \(j\), pares diferentes podem ter graus de liberdade diferentes.

6.4 O que o resultado informa?

Para cada par de grupos, o Games–Howell apresenta:

6.4.1 Diferença

\(\bar y_i-\bar y_j\)

6.4.2 Intervalo

Intervalo de confiança simultâneo

6.4.3 Decisão

\(p\)-valor ajustado

Se o \(p\)-valor ajustado for menor que \(\alpha\), há evidência de diferença entre aquele par de médias.

6.5 Qual caminho seguir?

6.5.1 Variâncias semelhantes

  1. ANOVA clássica
  2. Tukey–Kramer, se necessário

6.5.2 Variâncias diferentes

  1. ANOVA de Welch
  2. Games–Howell, se necessário

A escolha deve considerar o planejamento do estudo, os tamanhos amostrais, gráficos dos resíduos e evidências sobre a igualdade das variâncias.

6.6 Síntese

6.6.1 ANOVA clássica

Usa uma variância residual comum para testar a igualdade das médias.

6.6.2 Welch

Pondera os grupos pela precisão e ajusta os graus de liberdade.

6.6.3 Games–Howell

Compara os pares sem exigir uma variância comum.

Heterogeneidade não impede a comparação das médias; ela exige um procedimento compatível com os dados.
